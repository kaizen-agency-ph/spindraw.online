From live chat to winner

  1. Tell chat the entry word, for example !join.
  2. Copy the chat messages and paste them using the Live chat lines format. Timestamps are removed automatically.
  3. Type !join as the keyword and keep “One entry per person” on, so spamming the word doesn’t add chances.
  4. Lock, take a salt word from chat, and press Space.

Members and super chats

To reward channel members, add them on separate lines with a multiplier, such as @gamerjoe x3. Their slice grows and so do their odds. The verify page lists every entry with its weight, so it stays transparent.

Sharing the result

YouTube live chat messages are capped at 200 characters, which is too short for most verify links. Post the link in the video description or a pinned comment instead. Regular YouTube comments allow much longer text.

Questions

Can it pull YouTube chat automatically?

Not yet. For now you paste the chat. Automatic YouTube and Twitch chat import is on the roadmap.

Will duplicate names count twice?

Not with “One entry per person” on. Names are compared ignoring capital letters and extra spaces.

Can I do several prizes in one stream?

Yes. List prizes in draw order in the Prizes tab. Winners are removed from the wheel after each draw unless you turn that off.
