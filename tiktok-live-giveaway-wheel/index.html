Set it up in TikTok LIVE Studio or OBS

  1. Open the control panel, go to the Stream tab and choose 9:16 (TikTok, Reels, Shorts).
  2. Copy the overlay URL.
  3. In TikTok LIVE Studio, add a Link source and paste the URL at 1080×1920. In OBS, add a Browser source with the same size.
  4. Keep the control panel open in your browser. The overlay follows every spin automatically.

If a link source shows up blank or tiny in TikTok LIVE Studio, run the overlay in OBS instead and send OBS to TikTok with the OBS Virtual Camera.

Collecting TikTok entries

TikTok comments scroll away fast. Two reliable options:

  • Paste comments: for a giveaway on a video post, copy the comments from TikTok on the web and use the Copied comments format with your keyword.
  • Google Form: put a form link in your bio, then import the responses as CSV or straight from Google Sheets. Name and ticket columns are detected automatically.

Proof that fits TikTok

TikTok comments are limited to 150 characters, so a full verify link usually won’t fit. Download the proof file instead and share it from your bio link or a story. Anyone can open it on the SpinDraw verify page.

Questions

Does the overlay work in TikTok LIVE Studio?

Yes, as a Link source at 1080×1920. If your version renders link sources badly, use OBS with the Virtual Camera instead.

Can viewers see that the draw wasn’t scripted?

The commitment code shown before the spin locks the entry list and the secret seed. After the raffle, the verify page re-runs every draw and anyone can compare the code with what they saw live.

Is there a limit on entries?

No fixed limit. Thousands of names spin smoothly. Very small slices hide their labels, and the ticker under the wheel shows whose slice the pointer is on.
