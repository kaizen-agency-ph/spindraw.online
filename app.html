      How SpinDraw works

      1. 1 Add entries

      Scroll the picture to see every numbered step.

      Who’s in the draw

      Add everyone who can win. Your list stays in your browser.

      1. Choose how you’re pastingOne name per line, copied comments or live chat lines. With comments, you can also count only those containing a keyword like #join.
      2. Paste your namesType or paste them here. “Juan x3” gives Juan three entries.
      3. Remove duplicatesKeep this ticked for one entry per person, even if someone commented twice.
      4. Or import a listUpload a CSV, or fetch a Google Sheet that anyone with the link can view.

      Scroll the picture to see every numbered step.

      What they can win

      List your prizes and decide what happens after each win.

      1. List prizes in draw orderOne per line. The first line is drawn first, so a common order is 3rd, 2nd, then 1st.
      2. Remove winnersKeep this on so nobody can win twice. It’s required when a game has more than one winner.
      3. Set a claim timerGive winners time to respond. Set it to 0 to turn it off.
      4. Track your prizesThis list shows what’s been won and what’s still left.

      Scroll the picture to see every numbered step.

      Pick winners, fairly

      Run the raffle from top to bottom, then share the proof.

      1. Lock the listThis freezes the entries and shows a code everyone can screenshot.
      2. Add a public word (optional)Ask someone else for any word after locking. It makes the result hard for anyone to steer.
      3. Start the drawPress Space. Then press C if the winner claims, or R to redraw a no-show.
      4. Finish and share proofThis creates a verify link that works for 7 days. Save the proof file to keep a permanent record.
      5. Download your recordsSave a winner card image or your results and entries as CSV files. New raffle starts over.

      Show it to everyone

      Set up a view for your stream, projector or video call.

      1. Pick a shape16:9 for YouTube, Facebook and Twitch, or 9:16 for TikTok, Reels and Shorts.
      2. Pick a backgroundTransparent for OBS and Streamlabs, green screen for chroma key, or dark for Zoom and Meet.
      3. Choose soundDecide whether the overlay plays sounds and music. If this tab plays sound too on the same computer, you’ll hear it twice.
      4. Copy the overlay linkAdd it as a Browser source in OBS or Streamlabs, or a Link source in TikTok LIVE Studio.
      5. Count down to the cutoffShows viewers how long they have left to enter.
      6. Show the codeKeeps the commitment code on the overlay so viewers can screenshot it.

      Make it yours

      Change the look and length. The overlay follows your style. Seasonal themes are in the Theme row above the game, and the Sound button at the top of the page turns all game audio on or off.

      1. Choose coloursPick a colour set, or customise the slices, text, rim, pointer and hub. Ball colours in the Ball Race follow these too.
      2. Add your logoPuts your logo in the middle of the wheel.
      3. Add a wheel imageSpins with the wheel, blended over the slices.
      4. Add a backgroundFills the overlay behind everything.
      5. Set the game lengthQuick, Normal or Epic, for the Ball Race, Horse Race and Pixel Battle.
