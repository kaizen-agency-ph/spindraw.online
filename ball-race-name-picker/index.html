      How to run a marble race with names

      1. Paste up to 100 names in the Entries tab above, one per line.
      2. Set How many winners?: 1 for a single winner, or more for a finishing order.
      3. Pick a length in the Style tab: Quick, Normal or Epic.
      4. Click Lock entries in the Draw tab so everyone sees the code before anything moves.
      5. Press Start race or Space. Click Present for a projector, a video call or a stream.

      Use a marble race for your fantasy draft order

      A marble race is a popular way for fantasy football, basketball and baseball leagues to set the draft order, because everyone can watch their own marble. To get the whole order:

      1. Paste every manager or team name, one per line.
      2. Set How many winners? to the number of teams, up to 50.
      3. Optional: in the Prizes tab, list 1st pick, 2nd pick and so on, so each finisher is labelled.
      4. Start the race. The first marble across gets the first pick, the second gets the next, and so on.
      5. Save the order with Results CSV, and share the verify link with the league.

      For a snake draft, use the finishing order for round one; your league app reverses it each round.

      Is the marble race fair?

      In many marble races the physics decide, so a marble’s starting spot can change its odds. In SpinDraw, a fair draw from the locked list picks the winners first. The race runs real physics from a seed with nothing steering any marble, and the drawn names go on the marbles that finish first. Each person’s chance is exactly their share of the entries, and the verify link lets anyone re-run the draw afterwards.

      Questions

      How many names can be in a marble race?

      Up to 100. For bigger lists, use the wheel or the slot machine, which handle thousands.

      Can I get a full finishing order?

      Yes. Set “How many winners?” to the number you need, up to 50, and the race runs until that many have finished, in order.

      Can I use it to set a fantasy football draft order?

      Yes. Set the number of winners to your league size and the finishing order is your draft order. Results CSV saves it, and the verify link lets the league check it.

      Is the marble race rigged?

      No one can steer it. The winners come from the locked draw, the same as the wheel, and the verify link shows the result came from the locked list.

      Do extra entries still count?

      Yes. Everyone gets one marble, but “Name x3” still gives that person three times the chance, because the draw uses the entries.
